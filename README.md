# Atalho do Meu Combustível

Este repositório contém somente a página de entrada e os ícones usados para instalar um atalho do Meu Combustível no iPhone ou Android. O código do aplicativo e os dados não ficam neste repositório.

## Publicar com GitHub Pages

1. No GitHub, abra **Settings > Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`; clique em **Save**.
4. Aguarde a publicação em `https://fragbh.github.io/meu-combustivel-atalho/`.

O site é público e contém o link do Web App do Google Apps Script. Para usar o aplicativo, é necessário entrar com uma Conta Google.
